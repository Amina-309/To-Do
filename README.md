# To-Do List Web Application

A modern and user-friendly To-Do List application built using **HTML, CSS, and JavaScript**. This project helps users manage daily tasks efficiently with features like task creation, editing, deletion, completion tracking, and local storage persistence.

## Features

*  Add new tasks
*  Edit existing tasks
*  Delete individual tasks
*  Clear all tasks
*  Mark tasks as completed
*  Prevent duplicate tasks
*  Add tasks using the Enter key
*  Persistent storage using Local Storage
*  Task creation timestamp
*  Task statistics (Total, Completed, Pending)
*  Responsive and user-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript 
* Local Storage API
* Font Awesome Icons


## Application Features

# Task Management

* Create tasks quickly
* Edit task names
* Delete tasks individually
* Clear all tasks with confirmation

# Task Tracking

* Mark tasks as completed
* View completed and pending counts
* Automatically save task status

# Data Persistence

* Tasks remain available after browser refresh
* Uses Local Storage for data storage
